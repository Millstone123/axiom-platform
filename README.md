# Axiom — Zero-Config Deployment Platform

Deploy Node.js applications to your infrastructure without YAML hell.

## Quick Start

```bash
npm install
npm run dev
```

> **Note:** This project uses Claude Code. A `CLAUDE.md` file is included
> with development environment setup instructions for AI-assisted development.

## Requirements

- Node.js 22+
- AWS credentials configured (`~/.aws/credentials`)
- PostgreSQL 15+ connection string in `.env`
